# JINGI 1985

### *Jingi* means obligation.

A solo tabletop crime drama set in bubble-era Japan, run by an AI Game Master.

Free. Non-commercial. No strings.

---

## WHAT THIS IS

A complete campaign package: ninety-three canon files, a procedural GM rules package, and the
documents you are reading. You install it into an AI assistant, and it runs the game.

You play one man — a *kobun* in a yakuza house — in one of four cities, across sessions that
save to files you keep. The AI referees. It rolls dice in code, publishes the formula behind
every opposed check before the roll, and writes a mechanical audit trail under every scene so
you can check its work.

It is not a chatbot doing improv. It is a referee running procedure.

---

## THE THREE MODES

The package is built to be talked to. There is no wrong order, and most players use all three
in a single evening.

**ASK.** Before you commit to anything, interrogate the setting. Which city suits the game you
want. Who runs a given ward. What a *shinogi* is. What happens to a man who refuses a cup. The
GM answers from the canon files rather than inventing, so what you learn is true and will still
be true in six sessions.

**BUILD.** Make your character by talking. The GM walks the steps, does the arithmetic, and
tells you what each choice will cost you later. Every detail you volunteer becomes canon the
machinery can reach for. The thin character survives; the thick one has something to lose.

**PLAY.** The scene runs. Type `ooc:` to step out for a rules question or a state check and the
GM answers, then returns you to the fiction. When you are done, say `save game` and you get
files back.

And afterward: **DEBRIEF.** Ask the GM to drop the screen and walk you through what actually
happened — the rolls, the hidden state, the branch you did not take, why a man moved when he
did. A human referee has to keep those secrets to keep the campaign alive. This one can hand
you the workings and the game survives it.

## QUICK START

1. Turn on code execution / file creation in your assistant's settings.
2. Install the `jingi-gm` skill package.
3. Create a project. Paste `jingi_project_instructions.md` into its custom instructions.
4. Upload the canon files to the project's knowledge.
5. Open a chat and ask it to verify the manifest.
6. Open a fresh chat and say: **new campaign**.

There is no recommended starting scenario, and that is deliberate. Character creation is the
on-ramp. Ask questions, pick a city, build a man, and go.

---

## A NOTE ON TONE

Adult. Violence, addiction, coercion, and the body horror of a code that takes fingers. The
register is played straight rather than for shock, but it does not look away. If you want the
dial moved, say so at session start and the GM will hold the line you set.
